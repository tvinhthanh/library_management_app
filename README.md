# library_management_app

Flutter client for a library management system — catalogue browsing, borrowing
and returns.

```
Frontend_Library/   Flutter app (Android · iOS · desktop targets)
.github/workflows/  CI build pipeline
demo/               recorded walkthrough
```

CI builds the app on every push, so a broken build is caught before it reaches a
device.

```bash
cd Frontend_Library && flutter pub get && flutter run
```
